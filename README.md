## `01` / COMMAND DECK

> **Detect with context. Investigate with evidence. Defend by design.**

INFOKOM-KI is the GitHub home for defensive cybersecurity work associated with **Information Security and Cryptography Division, Department of Communication and Informatics, Tangerang City Government**. We publish practical tooling for Security Operations Center (SOC) workflows, threat intelligence, detection engineering, and AI-assisted security analysis.

<table>
  <tr>
    <td width="50%" valign="top">
      <h3>◈ SOC Automation</h3>
      Build integrations that help security analysts retrieve, investigate, and contextualize security events.
    </td>
    <td width="50%" valign="top">
      <h3>◈ AI-Assisted Security</h3>
      Explore MCP-based tool access, retrieval, and structured investigation workflows, with analyst judgment in the loop.
    </td>
  </tr>
  <tr>
    <td width="50%" valign="top">
      <h3>◈ Threat Intelligence</h3>
      Connect indicators, malware-hash references, and external threat context to support defensive decisions.
    </td>
    <td width="50%" valign="top">
      <h3>◈ Detection Engineering</h3>
      Develop detection content for web compromise patterns, malicious SEO activity, and Unicode-confusable techniques.
    </td>
  </tr>
</table>
